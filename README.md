# 🧠 Страховая аналитика: сегментация клиентов по медицинским рискам

## 📦 Содержание
- `insurance_analysis.ipynb` — ноутбук с полным циклом анализа: от EDA и фичей до выводов;
- `insurance_small.csv` — исходный датасет;
- `README.md` — описание проекта и бизнес-контекста;

## 🔍 Что сделано
- Проведена очистка и разведочный анализ данных;
- Выявлены выбросы, экстренные случаи, поведенческие и возрастные риски;
- Построена **бизнес-сегментация клиентов**: кто тратит больше и почему;
- Для каждой группы предложен осмысленный подход;

## 💡 Основные выводы
- Малочисленные группы клиентов дают резкий рост затрат — экстренные случаи, поведенческие риски, старший возраст;
- Здоровые клиенты — стратегически ценная аудитория, которую стоит поощрять;
- В данных нет “скрытых” рисков (курящих с ожирением и низкими тратами), что подтверждает реализацию риска;
- Региональные отклонения по затратам предполагают возможность гео-настройки тарифов.

## 🚀 Как запустить
1. Установить Python 3.8+ и библиотеки (`pandas`, `seaborn`, `matplotlib`, `scipy`);
2. Установить и запустить Jupyter Notebook:
   
    `pip install notebook`
  
    `jupyter notebook`

3. Открыть `Wink.ipynb`;
4. Запустить все ячейки последовательно.
